## 1. アーキテクチャ概要

### 技術スタック

| 項目 | 採用技術 | 理由 |
|------|---------|------|
| フレームワーク | Flutter（Dart） | iOS/Android両対応・高品質アニメーション・型安全 |
| 音声再生 | just_audio | シームレスループ・安定した再生 |
| 音声DSP（終了時） | Platform Channel（AVAudioEngine / AudioEffect） | LPFリアルタイム処理 |
| バックグラウンド再生 | flutter_background_service | 画面を閉じても継続動作 |
| 設定永続化 | shared_preferences | 軽量なKey-Value保存 |

### アーキテクチャパターン

MVVM（Model-View-ViewModel）＋ Repository パターン

### ディレクトリ構成

```
lib/
├── main.dart
├── core/
│   ├── audio/          # Platform Channel + just_audio
│   ├── timer/          # タイマーロジック
│   └── settings/       # 設定の永続化（shared_preferences）
├── features/
│   ├── home/           # 設定画面（タイマーホイール・音源切替）
│   └── session/        # 実行中画面（没入モード）
└── shared/
    └── widgets/        # 共通UIコンポーネント

assets/
└── audio/
    ├── brown_noise.wav  # 高品質・シームレスループ用に編集済み
    └── green_noise.wav  # 同上
```

## 2. 画面設計・UIフロー

### 画面構成（2画面 ＋ 設定画面）

```
┌─────────────────────┐
│   ホーム画面（設定）  │
│                     │
│   ┌─────────────┐   │
│   │ タイマーホイール│  │
│   │  （大型円形） │   │
│   └─────────────┘   │
│                     │
│  [BROWN] ○──● [GREEN]│
│                     │
│    ⚙️  設定          │
│                     │
│   ▶ セッション開始   │
└─────────────────────┘
         ↓ 開始
┌─────────────────────┐
│   没入モード画面     │
│  （背景：深い土色/  │
│    深い森の影）      │
│                     │
│   残り時間（大型）   │
│                     │
│  （背景が呼吸に合わせ │
│    微細に明滅）      │
│                     │
│ ※長押し（0.8秒）で  │
│   停止ボタンが出現   │
└─────────────────────┘
         ↓ タイマー終了
  LPF + フェードアウト演出
  （光の輪が黒に沈む）
         ↓
    ホーム画面へ戻る
```

### 画面遷移の状態

| 状態 | 説明 |
|------|------|
| `idle` | ホーム画面・設定入力中 |
| `playing` | セッション実行中 |
| `fading` | フェードアウト演出中 |
| `completed` | 終了・ホームへ戻る |

中断時: `playing` → 長押し検知（0.8秒） → 停止ボタン表示（3秒）→ タップで `idle`

### カラーパレット

| 音源 | 背景色 | 説明 |
|------|-------|------|
| BROWN | `#1A120B` | 深い土色 |
| GREEN | `#0A2647` | 深い森の影 |

## 3. 音声システム設計

### 音声再生フロー

```
assets/audio/brown_noise.wav（またはgreen_noise.wav）
    ↓
just_audio（Dart層）
    └── loopingAudioSource  ← シームレスループ再生
            ↓
Platform Channel（終了フェーズのみ）
    ├── iOS:    AVAudioEngine → AVAudioUnitEQ（LPF）
    └── Android: AudioEffect → LowPassFilter
```

### 3つの再生フェーズ

| フェーズ | 処理内容 |
|---------|---------|
| **再生中** | just_audioでループ再生。CPU負荷なし |
| **フェードアウト開始** | 音量を設定時間（1〜5分）かけてカーブ状に低下 |
| **LPF適用** | カットオフ周波数を20kHz→200Hzへ段階的に下降。高音域から順に消えていく |

### LUFS補正

LPFで中音域が削られると聴感上の音量が下がりすぎるため、フィルタ適用量に応じてゲインを微補正し、自然な消え方を実現する。

### バックグラウンド再生

`flutter_background_service` を使用。画面を閉じてもタイマーと音声が継続動作。

## 4. タイマー・設定管理

### 状態管理（ViewModel）

```dart
class SessionViewModel extends ChangeNotifier {
  SessionState state;    // idle / playing / fading / completed
  Duration remaining;    // 残り時間
  Duration fadeDuration; // フェードアウト時間（1〜5分）
  NoiseType noiseType;   // brown / green
}
```

### タイマーホイール操作

- 円形のホイールを指でドラッグして1〜60分を設定
- 1分刻みのスナップ（触覚フィードバック付き）
- 設定した時間は中央に大きく表示

### フェードアウト開始タイミング

```
タイマー残り時間
├── 残り > フェード時間 → 通常再生
└── 残り ≦ フェード時間 → フェードアウト開始
         ↓
    タイマー完了 → 無音・画面暗転
         ↓
    ホーム画面へ静かに戻る
```

### 設定の永続化（shared_preferences）

| 設定項目 | デフォルト値 | 範囲 |
|---------|------------|------|
| タイマー時間 | 10分 | 1〜60分 |
| 音源種別 | BROWN | BROWN / GREEN |
| フェードアウト時間 | 1分 | 1〜5分 |
| 呼吸アニメーション | ON | ON / OFF |
| 終了演出 | ON | ON / OFF |
| 没入モード | ON | ON / OFF |

アプリを閉じて再起動しても前回の設定が復元される。

### 音量警告

アプリ初回起動時のみ「デバイス音量60%以下（80dB以下）を推奨します」というダイアログを表示。

## 5. 没入演出・アニメーション設計

### 設定画面のトグル項目

| 設定項目 | デフォルト | 説明 |
|---------|-----------|------|
| 呼吸アニメーション | ON | 背景の微細な明滅 |
| 終了演出 | ON | 光の輪が黒に沈むアニメーション |
| 没入モード | ON | ステータスバー・ナビゲーションバーを非表示 |

### 呼吸アニメーション（実行中画面）

```
基本色（例：BROWN = #1A120B）
    ↓ 4秒かけて微細に明るく（+8%輝度）
    ↓ 4秒かけて元の暗さに戻る
    ↓ 繰り返し（人間の平均呼吸ペース：約7.5回/分）
```

- Flutter の `AnimationController` + `CurvedAnimation（Curves.easeInOut）` で実装
- OFFの場合：背景色は固定、アニメーションなし

### 終了演出（LPFと同期）

```
フェードアウト開始
    ├── 音声: LPF カットオフ 20kHz → 200Hz（線形）
    └── 画面: 中央の光の輪が半径縮小 + 輝度低下
             ↓
        音量ゼロ到達と同時に
             ↓
        画面が完全に暗転（3秒）
             ↓
        ホーム画面へ静かに戻る
```

- OFFの場合：フェードアウト中も画面変化なし、静かに暗転して終了

### 没入モード

- ONの場合：`SystemChrome.setEnabledSystemUIMode(SystemUiMode.immersiveSticky)` でステータスバー・ナビゲーションバーを非表示
- OFFの場合：ステータスバーを常時表示（通知・時刻が確認できる）
- `WakeLock` で画面スリープを防止（モード問わず常時有効）

### 長押し停止操作（誤操作防止）

- 0.8秒の長押しで停止ボタンが中央にフェードイン
- 停止ボタンは3秒間表示後に自動で消える
- タップで即時停止 → ホームへ戻る
