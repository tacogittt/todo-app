ブログ執筆特化型ウェブアプリケーション 設計書

1. システム概要
   ユーザーがAI（ChatGPT/Claude等）をパートナーとして、\*\*「テーマ入力 → 構成設計 → セクション執筆 → 公開」\*\*というステップを迷わず進められる、ウィザード形式のブログ執筆支援アプリ。
2. システム構成・技術スタック
   • 開発・実行環境: MANUS（自律型開発エージェント）、Claude Code, \[User History]
   • AIライブラリ: LangChain（各タスクを鎖のように繋ぎ、一連の処理を自動化する）,
   • 主要API:
   ◦ LLM API: OpenAI (gpt-4o) / Anthropic (Claude 3.5 Sonnet),
   ◦ リサーチ: Google Custom Search API（RAG: 検索拡張生成）,
   ◦ 公開連携: WordPress REST API（ブログへの直接下書き投稿）,
   ◦ 画像生成: DALL-E 3 等
3. 主要機能の仕様（執筆ステップ）
   ステップ1：テーマ入力とペルソナ・トーン設定
   • 機能: ユーザーがテーマを入力。AIがターゲット（ペルソナ）や記事のトーンを提案する,。
   • UI: 「やさしい先生風」「ビジネス専門家」などのロール（役割）をボタンで選択可能にする,。
   ステップ2：目次（構成）の構築
   • UI構成:
   ◦ 左画面（設計図）: 目次（H2/H3）のリスト。ドラッグ＆ドロップで並べ替え可能 \[User History]。
   ◦ 右画面（AI相談窓口）: 選択した見出しへのアドバイスや、文字数・キーワードのチェック結果を表示 \[User History]。
   • ロジック: 読者の\*\*「疑問の順番」\*\*（基本→必要性→差別化→行動）に沿った構成をAIが提案する,。
   • 編集機能: 特定のセクションのみの「再生成」や、30文字以内への「短縮リライト」機能, \[User History]。
   ステップ3：セクション単位の執筆
   • 機能: 確定した目次に基づき、1項目ずつ本文を生成する。一括生成を避け、内容の正確性と文脈の一貫性を保つ,。
   • コンテキスト維持: LangChainのMemory機能を用い、前のセクションの内容をAIが引き継ぐ。
   ステップ4：校正とWordPress投稿
   • 機能: 誤字脱字チェック、SEOメタデータの自動生成,。
   • 出力: WP REST APIを用い、タイトル、本文、タグをセットしてWordPressの「下書き」へ保存する,,。
4. プロンプトエンジニアリング戦略
   • Chain of Thought (CoT): AIに推論ステップを生成させ、論理的な破綻を防ぐ,。
   • Step-Back Prompting: 抽象的な問いを挟むことで、読者の検索意図をより深く反映させる,。
   • ハルシネーション対策: 検索結果（RAG）を指示（プロンプト）に含め、事実に基づいた生成を行う,。
5. UI/UX 開発のポイント
   • 進捗の可視化: ユーザーが現在のステップを常に把握できるプログレスバーを表示する \[User History]。
   • クイック指示ボタン: 「もっと具体的に」「短く」など、複雑な指示を入力せずとも操作できるボタンを配置する \[User History]。
   • 直感的な操作: 初心者が迷わない、シンプルで分かりやすい機能配置を徹底する
