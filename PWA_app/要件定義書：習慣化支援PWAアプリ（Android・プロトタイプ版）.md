# 要件定義書：習慣化支援PWAアプリ（Android・プロトタイプ版）

## 1. プロジェクト概要
*   **コンセプト**: 「継続する技術（習慣化）」をWeb標準技術で具現化し、ユーザーの再訪と定着を促進する。 [1-3]
*   **開発目標**: 
    *   追加費用ゼロでローカルPC開発を完結させる。 [4, 5]
    *   Android実機のホーム画面からワンタップで起動し、ネイティブアプリ同様の挙動を確認する。 [6-8]
*   **ターゲット**: Android（Chromeブラウザ）。 [9-11]

## 2. 技術スタック（最小構成・無償）
*   **バックエンド**: PHP 8.3 / Laravel 12。 [5]
*   **データベース**: **SQLite**（サーバー構築不要、プロジェクト内の1ファイルで完結）。 [5, 12]
*   **PWA基盤**: `laravelpwa` パッケージ（manifest.json および Service Worker の自動生成）。 [6, 13]
*   **フロントエンド**: Tailwind CSS（直感的なUI構築）。 [5, 14]
*   **テスト手法**: **USBポートフォワーディング**（PCのlocalhost:8000を実機で認識）。 [5, 15]

## 3. 主要機能要件

### 3.1 インストールと表示 (Installable)
*   **ホーム画面への追加**: `manifest.json` により、スマホのホーム画面にアイコンを設置。 [1, 6, 8]
*   **スタンドアロン表示**: アドレスバーを排したフルスクリーン表示による没入感の提供。 [14, 16, 17]
*   **Rich Install UI**: 画像と説明を伴うリッチなインストール誘導（Android Chrome特有機能）。 [11]

### 3.2 習慣化を支えるエンゲージメント (Capable)
*   **プッシュ通知 (Web Push API)**: 指定時間にリマインドを送信。画像付き通知によるクリック率（CTR）向上（最大56%増）を狙う。 [11, 18, 19]
*   **アプリバッジ (App Badge API)**: アイコン上に未処理タスク数をバッジ表示し、視覚的に再訪を促す。 [11, 20]
*   **高速表示**: プリキャッシュにより、2回目以降の起動を瞬時に行う。 [2, 21, 22]

### 3.3 信頼性とオフライン対応 (Reliable)
*   **Service Worker**: 静的リソース（CSS/JS）をキャッシュ。通信環境が悪い場所でもアプリを起動。 [7, 21, 23, 24]
*   **オフライン専用画面**: 通信遮断時にユーザーを混乱させない専用メッセージの表示。 [13, 25]

## 4. 開発・検証手順
*   **HTTPS要件の回避**: PWAには通常HTTPSが必須だが、USBデバッグによる `localhost` 接続でこの制約を回避してテストを行う。 [26-28]
*   **DB管理**: プッシュ通知の購読情報（エンドポイント等）および習慣化ログを SQLite に保存。 [29-31]

## 5. セキュリティ・リスク管理
*   **権限の分離**: PWAの権限は「ドメイン単位」で管理されるため、将来の公開時は専用ドメインでの運用を推奨（権限リークの防止）。 [32-35]
*   **ブラウザ更新**: 特定のAPIクエリによるクラッシュ問題を避けるため、テスト端末のChromeを最新版（v131以降推奨）に保つ。 [36-38]
*   **生体認証の除外**: 今回の要件からは WebAuthn 等の生体認証機能は除外する。
