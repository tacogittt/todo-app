# 売上分析ダッシュボード - 実装機能一覧と技術的ポイント

## プロジェクト概要

CSVデータ（300件の取引レコード）を可視化した、完全日本語対応のモダン売上分析ダッシュボード。React 19 + Tailwind CSS 4 + Recharts を基盤に、複数の分析機能を実装。

---

## 実装機能詳細

### 1. KPI カード表示（総売上、注文数、顧客数、平均注文金額）

**概要**
ダッシュボード上部に4つの主要指標を大きく表示するカード型UI。ページ読み込み時に段階的フェードインアニメーションで表示。

**技術的ポイント**
- **ライブラリ**：shadcn/ui の Card コンポーネント、Lucide React アイコン
- **実装方法**：
  - `calculateKPIMetrics()` 関数で売上、注文数、顧客数を集計
  - Tailwind CSS の `@keyframes` でカスタムアニメーション定義（`animate-fade-in-up`）
  - `stagger-{n}` クラスで段階的遅延表示（`animation-delay` を計算）
- **ツールチップ機能**：Radix UI の `Tooltip` コンポーネントで KPI 定義を表示
- **フォーマット**：`toLocaleString('ja-JP')` で日本式数値表記（¥5,748,734）

**ファイル**
- `client/src/components/KPICard.tsx`
- `client/src/lib/dataProcessor.ts` → `calculateKPIMetrics()`

### 2. ライト/ダークテーマ切り替え機能

**概要**
ヘッダー右上のボタンでテーマ切り替え。ユーザーの選択をブラウザに永続化し、次回訪問時も維持。

**技術的ポイント**
- **ライブラリ**：`next-themes` パッケージ（ThemeProvider）
- **実装方法**：
  - `ThemeProvider` で `defaultTheme="light"` を設定
  - `useTheme()` フックで現在のテーマと切り替え関数を取得
  - ローカルストレージに選択テーマを自動保存
- **CSS 変数**：`index.css` で `:root` と `.dark` セレクタに OKLCH カラーを定義
  - ライトテーマ：白背景（oklch(1 0 0)）、暗いテキスト
  - ダークテーマ：深い背景（oklch(0.141 0.005 285.823)）、明るいテキスト
- **コンポーネント対応**：Recharts チャート、shadcn/ui コンポーネント、カスタム CSS が自動的にテーマに適応

**ファイル**
- `client/src/contexts/ThemeContext.tsx`
- `client/src/components/ThemeToggle.tsx`
- `client/src/App.tsx` → ThemeProvider 設定
- `client/src/index.css` → テーマ CSS 変数定義

### 3. 日付範囲フィルター機能

**概要**
ヘッダーの「期間フィルター」ボタンをクリックするとポップオーバーが表示。開始日・終了日を選択してデータを絞り込む。リセットボタンで全データに戻す。

**技術的ポイント**
- **ライブラリ**：shadcn/ui の Popover、Input コンポーネント
- **実装方法**：
  - `DateRange` 型で `{ startDate: string; endDate: string }` を管理
  - `filterDataByDateRange()` 関数で日付範囲フィルタリング
  - 日付文字列を `new Date()` で比較（ISO 8601 形式）
  - フィルター適用時に全ての依存する状態（KPI、チャート）を自動更新
- **状態管理**：React `useState` で `dateRange` を管理、`useEffect` で連鎖更新
- **UI フィードバック**：フィルター件数をヘッダーに表示

**ファイル**
- `client/src/components/DateRangeFilter.tsx`
- `client/src/lib/dataProcessor.ts` → `filterDataByDateRange()`
- `client/src/pages/Home.tsx` → フィルター状態管理

---

### 4. CSV エクスポート機能

**概要**
ヘッダーの「エクスポート」ボタンでドロップダウンメニュー表示。2つのエクスポートオプション：
- 取引データ（全カラム）
- KPI サマリー（集計データ）

**技術的ポイント**
- **ライブラリ**：ネイティブ JavaScript（Blob、URL.createObjectURL）
- **実装方法**：
  - CSV 形式を手動生成（BOM ヘッダー付き：`\uFEFF` で Excel の日本語対応）
  - 配列データを `map()` で CSV 行に変換
  - 改行を `\r\n` で統一（Windows 互換）
  - `Blob` オブジェクトを作成し、`URL.createObjectURL()` で ダウンロードリンク生成
  - `<a>` タグの `download` 属性でファイル名を指定
- **ファイル名**：タイムスタンプ付き（`sales_data_20260117_012000.csv`）
- **フィルター連携**：現在のフィルター条件が適用されたデータのみエクスポート

**ファイル**
- `client/src/components/ExportButton.tsx`
- `client/src/lib/csvExport.ts` → CSV 生成関数

### 5. ドリルダウン分析機能

**概要**
チャート（円グラフ、棒グラフ）をクリックすると詳細分析モーダルが表示。該当カテゴリー/地域/年齢層の詳細データを表示。

**技術的ポイント**
- **ライブラリ**：React Context API、shadcn/ui の Dialog コンポーネント
- **実装方法**：
  - `DrilldownContext` で ドリルダウン状態を管理（`{ type, value, isOpen }`）
  - Recharts の `onClick` ハンドラで `setDrilldown()` を呼び出し
  - モーダル内で `calculateCategoryMetrics()` など条件付き集計関数を実行
  - 月別推移、支払方法別、年齢層別の複数チャートを表示
- **チャート操作**：
  - `<PieChart>` の `onClick={(entry) => setDrilldown('category', entry.category)}`
  - `<BarChart>` の `onClick={(entry) => setDrilldown('region', entry.region)}`
- **モーダル内容**：Recharts で複数チャートをレスポンシブ表示

**ファイル**
- `client/src/contexts/DrilldownContext.tsx`
- `client/src/components/DrilldownDetail.tsx`
- `client/src/pages/Home.tsx` → ドリルダウン状態管理

### 6. 詳細検索フィルター機能

**概要**
ヘッダーの「詳細検索」ボタンをクリックするとモーダルが表示。顧客 ID、支払方法、性別で複合フィルタリング。日付範囲フィルターと組み合わせ可能。

**技術的ポイント**
- **ライブラリ**：shadcn/ui の Dialog、Select、Input コンポーネント
- **実装方法**：
  - `FilterContext` で フィルター状態を管理（`{ customerId, paymentMethod, gender }`）
  - `filterDataBySearchCriteria()` 関数で複合条件フィルタリング
  - 顧客 ID：`includes()` で部分一致検索
  - 支払方法・性別：完全一致（空文字列で全選択）
  - 複数条件は `&&` で AND 結合
- **重複排除**：`Array.from(new Set(paymentMethods)).sort()` で支払方法の重複を排除
- **状態管理**：`useEffect` で `filters` 変更時に `localFilters` を更新
- **UI フィードバック**：アクティブフィルターを表示、リセットボタンで全クリア

**ファイル**
- `client/src/contexts/FilterContext.tsx`
- `client/src/components/SearchFilterPanel.tsx`
- `client/src/lib/dataProcessor.ts` → `filterDataBySearchCriteria()`

## データ処理アーキテクチャ

### データフロー

```
CSV ファイル (sample-data.csv)
    ↓
loadSalesData() → SalesData[] 配列
    ↓
フィルター処理（日付、顧客ID、支払方法、性別）
    ↓
集計処理（KPI、カテゴリー、地域、年齢層、支払方法）
    ↓
チャート・カード表示
```

### 主要関数（dataProcessor.ts）

| 関数名 | 入力 | 出力 | 用途 |
|--------|------|------|------|
| `loadSalesData()` | なし | `SalesData[]` | CSV データ読み込み |
| `calculateKPIMetrics()` | `SalesData[]` | `KPIMetrics` | KPI 計算 |
| `calculateCategoryMetrics()` | `SalesData[]` | `CategoryMetrics[]` | カテゴリー別集計 |
| `calculateRegionalMetrics()` | `SalesData[]` | `RegionalMetrics[]` | 地域別集計 |
| `calculateTimeSeriesData()` | `SalesData[]` | `TimeSeriesData[]` | 月別推移 |
| `calculateAgeGroupMetrics()` | `SalesData[]` | `AgeGroupMetrics[]` | 年齢層別集計 |
| `calculatePaymentMethodMetrics()` | `SalesData[]` | `PaymentMethodMetrics[]` | 支払方法別集計 |
| `filterDataByDateRange()` | `SalesData[]`, `DateRange` | `SalesData[]` | 日付フィルター |
| `filterDataBySearchCriteria()` | `SalesData[]`, `Filters` | `SalesData[]` | 詳細検索フィルター |
| `getUniquePaymentMethods()` | `SalesData[]` | `string[]` | 支払方法リスト取得 |

## パフォーマンス最適化

1. **データ処理の最適化**
   - CSV データは初回読み込み時のみ処理
   - フィルター適用時は既存データから再集計（再読み込みなし）
   - `useMemo` で計算結果をキャッシュ

2. **レンダリング最適化**
   - コンポーネント分割で不要な再レンダリングを回避
   - Recharts は自動的に最適化

3. **アニメーション最適化**
   - CSS アニメーション（GPU 加速）を使用
   - Framer Motion で スムーズなトランジション
